# Animated Wallpaper for Linux Wayland

> **Plug-and-play animated video and GIF wallpaper engine for COSMIC Desktop with NVIDIA Wayland support.**

Supports **videos** (MP4, WebM, MKV, AVI, MOV), **GIFs**, and **static images** (PNG, JPG, WEBP).
Built with a native C Wayland engine, a Python supervisor daemon, and a GTK4/Libadwaita GUI — no browser, no Electron, no X11.

![Animated Wallpaper for Linux Wayland](https://raw.githubusercontent.com/AlanDrone/Animated-Wallpaper-for-Linux-wayland/main/screenshot.png)

---

## Features

- 🎬 **Animated video wallpapers** — MP4, WebM, MKV, AVI, MOV.
- 🎞 **GIF wallpapers** — animated GIFs rendered natively via mpv.
- 🖼 **Static image wallpapers** — PNG, JPG, WEBP with infinite display.
- 🖥 **Native Wayland** — uses `wlr-layer-shell` protocol, fully compatible with COSMIC Desktop (`cosmic-comp`).
- 🎛 **Beautiful GUI** — GTK4 / Libadwaita, drag-and-drop, live gallery with thumbnails.
- ⚡ **Scaling modes** — Fit, Fill (pan-and-scan), or Stretch — switchable live without restart.
- 🛡️ **NVIDIA 4K fix** — Videos above 1080p are handled via mpv native downscaling (avoids `GL_INVALID_OPERATION` on DVI-D-1 outputs).
- 🔄 **Auto-restore** — Last wallpaper is automatically reapplied on login.
- ▶️ **Play / Pause / Stop** — Full playback control from the GUI or CLI.
- 🔇 **Silent** — Audio is always muted; wallpapers run quietly in the background.
- 🗂 **Persistent library** — Your media library survives reboots, stored at `~/.config/cosmic-wallpaper/library.json`.
- 🚀 **Autostart toggle** — One-click to enable/disable launch at login.

| Dependency | Package | Why |
|---|---|---|

### Install all dependencies at once

```bash
sudo apt install build-essential libwayland-dev libwayland-egl1 \
    libegl1 libgl1 libmpv2 ffmpeg python3-gi gir1.2-adw-1 python3-pil
```

## Installation

### Option 1 — Run directly (no install required)

```bash
git clone https://github.com/AlanDrone/Animated-Wallpaper-for-Linux-wayland.git
cd Animated-Wallpaper-for-Linux-wayland
./run.sh
```

`run.sh` auto-compiles the engine on the first run and opens the GUI immediately.

### Option 2 — Install system-wide (adds to app menu)

```bash
git clone https://github.com/AlanDrone/Animated-Wallpaper-for-Linux-wayland.git
cd Animated-Wallpaper-for-Linux-wayland
./install.sh
```

After installation, search for **"Cosmic Wallpaper"** in your COSMIC application menu.

## Usage

### Graphical Interface (GUI)

1. Open **Cosmic Wallpaper** from your app menu, or run `./run.sh`.
2. **Drag and drop** a video, GIF, or image into the window — or click **Add Media**.
3. Select your **Monitor** and **Scaling** mode.
4. Click **Set as Wallpaper**.

### Command Line (CLI)

```bash
# Set a wallpaper
cosmic-wallpaper-client set /path/to/video.mp4

# With options
cosmic-wallpaper-client set /path/to/video.mp4 --output DVI-D-1 --scaling fill

# Control playback
cosmic-wallpaper-client pause
cosmic-wallpaper-client resume
cosmic-wallpaper-client toggle
cosmic-wallpaper-client stop

# Check status
cosmic-wallpaper-client status
cosmic-wallpaper-client outputs
```

#### Scaling modes

| Mode | Description |
|---|---|
| `fit` (default) | Preserves aspect ratio; black bars if video and screen ratios differ |
| `fill` | Pan-and-scan: crops to fill the screen without black bars |
| `stretch` | Stretches to cover all 4 edges, ignoring aspect ratio |

## Why Does This Exist?

Pop!_OS 24.04 ships the new **COSMIC Desktop**, which uses its own Wayland compositor (`cosmic-comp`). Existing animated wallpaper tools like `mpvpaper` and `swww` crash silently on this setup due to:

- COSMIC-specific `wlr-layer-shell` configuration requirements (`exclusive_zone=-1`).
- NVIDIA driver conflicts when using `vf=scale` hardware filter pipelines on OpenGL surfaces.
- The `1920×1024` surface bug (COSMIC panel reserves 56px unless `exclusive_zone=-1` is set).

This project solves all three issues with a purpose-built engine.

---

## Technical Details

- **Protocol**: `wlr-layer-shell-unstable-v1` — layer surface at the bottom of the stack.
- **Rendering**: EGL context created on a `wl_egl_window`, rendered into by `mpv`'s OpenGL render context.
- **Scaling**: Implemented via mpv native properties (`panscan`, `keepaspect`, `video-zoom`) — no `vf=scale` software filter, avoiding hardware surface conversion errors.
- **IPC**: UNIX Domain Socket at `$XDG_RUNTIME_DIR/cosmic-wallpaper.sock` (JSON protocol).
- **4K handling**: `ffprobe` detects resolution before launch; mpv downscales natively.
